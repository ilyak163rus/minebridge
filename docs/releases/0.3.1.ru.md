## Быстрое заполнение области

```python
from minebridge import Minecraft, block

with Minecraft.create("localhost", 4711) as mc:
    mc.setBlocks(0, 80, 0, 29, 109, 29, block.COBBLESTONE)
    mc.flush()
```

Обе границы включаются: пример ставит **30×30×30 = 27 000 блоков**. При готовых чанках области до 32 768 блоков обрабатываются одним ограниченным проходом игрового потока. Большие области строятся порциями; предел одного запроса — 1 000 000 блоков.

Сохраняются состояния блоков, физика, загрузка чанков и подтверждение после завершения. Генерация новых чанков и тяжёлая физика могут увеличить время выполнения. Это не атомарная транзакция; универсальное время выполнения не гарантируется.

## Селектор по нику

```python
from minebridge import Minecraft, selector, items, effects

with Minecraft.create("localhost", 4711) as mc:
    player = selector.playerByName("YourNick")
    mc.players.giveItem(player, items.EMERALD, 3)
    mc.effects.add(player, effects.SPEED, 100, 200)
    mc.setPos(player, 10, 80, 10)
```

Ник состоит из 1–16 ASCII-букв, цифр или `_`; регистр должен точно совпадать. Поиск онлайн-игрока выполняется при каждом запросе. SELF этим не назначается.

Если игрок не найден, групповые команды получают пустую выборку. Методы, требующие ровно одного игрока, возвращают ошибку выбора. Для фильтров подписки событий используйте `players="YourNick"`, PlayerRef, ALL_PLAYERS или SELF: `playerByName` там не принимается.

## Понятная ошибка мирной сложности

```python
from minebridge import Minecraft, entity, errors

with Minecraft.create("localhost", 4711) as mc:
    try:
        mc.spawnEntity(0, 80, 0, entity.GIANT)
    except errors.PeacefulSpawnError:
        print("Не могу создать моба: установлен мирный режим")
```

Сложность проверяется в мире назначения непосредственно перед созданием. Ошибка содержит `code="PEACEFUL_SPAWN_BLOCKED"` и `outcome="not-applied"`; соединение остаётся рабочим. Minebridge не меняет сложность автоматически.

Проверяется правило конкретного типа Minecraft, а не только категория Monster. Отмена спавна другим плагином не выдаётся за мирную сложность. [Технический контракт](../contracts/V0_3_1_SPAWN_CONTRACT.ru.md).
