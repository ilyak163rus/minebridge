# Minebridge 0.3.1

## Мирная сложность

```python
from minebridge import Minecraft, entity, errors

with Minecraft.create("192.168.0.200", 4712) as mc:
    try:
        mc.spawnEntity(0, 80, 0, entity.GIANT)
    except errors.PeacefulSpawnError:
        print("Не могу создать этого моба: в мире установлен мирный режим")
```

Исключение содержит `code="PEACEFUL_SPAWN_BLOCKED"` и `outcome="not-applied"`.
Сложность проверяется в мире назначения непосредственно перед созданием,
в том числе после ожидания чанка. Соединение остаётся пригодным для следующих
команд. Minebridge не меняет сложность автоматически.

Проверяется реальное правило типа Minecraft, а не просто принадлежность к
Monster: Giant/Zombie запрещены, Shulker разрешён этим правилом. Отмена спавна
другим плагином не выдаётся за ошибку мирного режима.
[Точный контракт](../contracts/V0_3_1_SPAWN_CONTRACT.ru.md).

## Заполнение области

Внутри открытого соединения `mc`, после импорта `block`:

```python
mc.setBlocks(0, 80, 0, 29, 109, 29, block.COBBLESTONE)
mc.flush()
```

Обе границы включаются: этот пример ставит **30×30×30 = 27 000 блоков**.
Координаты от 0 до 30 включительно дали бы 31×31×31 = 29 791 блок.

При готовых чанках область до 32 768 блоков выполняется одним ограниченным
проходом на игровом потоке. Прежнее обязательное деление по 256 блоков на тик
для неё снято. Большие области сохраняют продолжения, бюджет времени и
очерёдность между сессиями. Максимальный объём запроса остаётся 1 000 000 блоков.

Сохраняются BlockData/состояния, физика, проверки координат, защита пересекающихся
запросов Minebridge и освобождение chunk tickets. Подтверждение приходит после
завершения. Это не атомарная транзакция и не обещание нулевого времени:
генерация новых чанков и тяжёлая физика могут увеличить задержку серверного тика,
как и большой vanilla fill. Блоки устанавливаются через Paper API, без NMS
или подстановки текстовой команды.

Это согласованное изменение политики производительности 0.3.1; исторический
контракт 0.2 о 256 блоках / 2 мс не определяет новый быстрый путь.

На локальном Paper 133 медиана этого куба с flush составила **0.0665 с**
вместо **5.286 с** на 0.3.0. Полный readback подтвердил каждый блок.
[Условия и границы замера](../reports/V0_3_1.ru.md).

## Селектор игрока по нику

```python
from minebridge import Minecraft, selector, items, effects

with Minecraft.create("192.168.0.200", 4712) as mc:
    player = selector.playerByName("YourNick")
    mc.players.giveItem(player, items.EMERALD, 3)
    mc.effects.add(player, effects.SPEED, 100, 200)
    mc.setPos(player, 10, 80, 10)
    mc.inventories.ofPlayer(player).setItem(0, items.DIAMOND, 1)
```

Сигнатура: `playerByName(name: str) -> Selector`. Создание селектора локально
и не требует подключения. Выражение — `@a[name=YourNick,limit=1]`; допустим
ник из 1–16 ASCII-букв, цифр или `_`, с **точным регистром**. Выбор происходит
при каждом запросе и не назначает SELF.

Если игрока нет онлайн, групповые команды получают пустую выборку; методы,
требующие ровно одного игрока, возвращают существующую ошибку выбора.
Фильтр подписки событий сохраняет отдельный контракт: используйте
`players="YourNick"` или PlayerRef, ALL_PLAYERS/SELF. Произвольные выражения
Selector, включая выражение нового helper, там не принимаются.

## Установка и публикация

Обновляйте **обе части** до 0.3.1. Локальные файлы выпуска находятся
в `dist/v0.3.1/`: JAR, wheel, sdist, SHA256SUMS и сведения о проверках.
После публикации они доступны в
[GitHub Releases](https://github.com/ilyak163rus/minebridge/releases).

```shell
python -m pip install --upgrade --force-reinstall --no-deps minebridge-0.3.1-py3-none-any.whl
```

[Установка сервера](../QUICKSTART.ru.md), [API](../API_V0_3.ru.md),
[порядок публикации](../PUBLISHING.ru.md). Подготовка файлов и workflow сама
по себе не означает, что репозиторий или пакет уже опубликованы.
