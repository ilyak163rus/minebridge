# Документация Minebridge

Minebridge состоит из Python-библиотеки и серверного плагина Paper. Для работы
нужны обе части. Текущая версия — **0.3.1**, Python 3.11+, Paper 26.2 / Java 25.

Начать работу:

1. [Установка плагина и библиотеки](QUICKSTART.ru.md).
2. [Блоки, игроки, предметы, эффекты и сущности](API_V0_2.ru.md).
3. [События, слоты, управление игрой и дополнения 0.3.1](API_V0_3.ru.md).
4. [Примеры Python](../examples).

Справочники API 0.2/0.3 описывают действующие предметные модули; это не требование
устанавливать старые версии. Планы и отчёты в `reports/` сохраняют историю.
Каталоги `dist/`, `.work/`, локальные серверы и интеграционные журналы не входят
в Git-репозиторий; бинарные файлы и итоговые сведения о выпуске прикладываются
к GitHub Release после публикации.
