# Minebridge documentation

Minebridge is a Python library and a Paper server plugin. Install **both parts from the same release**. Current release: **0.3.1** · Python **3.11+** · Paper **26.2** · Java **25**.

1. [Getting started](en/GETTING_STARTED.md) — plugin, library, first program and LAN setup.

3. [Recipes](en/RECIPES.md) — building, rewards, events and inventories.
4. [Runnable examples](../examples/README.md).
5. [Moving from mcpi / RaspberryJuice](MIGRATING_FROM_MCPI.md).
