I05 / Minebridge 0.3.0 — общая приёмка и поставка
=================================================

29 октября 2026 года. I05 завершена: установленные библиотека и плагин 0.3.0
прошли совместную приёмку на настоящем Paper. Выпущен локальный комплект
[dist/v0.3](../../dist/v0.3/README.ru.md). Это одна итоговая поставка после I01–I04;
в PyPI пакет не публиковался. Исторические dist/v0.2 и dist/v0.2.1 сохранены.

Что вошло
---------

Согласованные возможности I01–I04: управление игроками и миром, позиционные
эффекты, setPos, 14 типов событий с обработчиками/историей/фильтрами, точные
слоты сундуков и игроков. I05 фиксирует версию, проверяет совместную работу,
упаковку и подсказки; новые предметные функции не добавлялись.

Сохранены два параметра create, необязательные token/world, buffered по
умолчанию, ожидание записей при обычном выходе Python и logging=False.
SELF задаётся текущим онлайн-ником, без привязки к компьютеру ученика.
[API](../API_V0_3.ru.md), [быстрый запуск](../QUICKSTART.ru.md),
[общий пример занятия](../../examples/v03_lesson.py).

Приёмка на Paper
----------------

Все 19 групп основной сводки прошли. Использованы два отдельных Python-процесса
с установленным wheel и два настоящих игровых TCP-подключения I05Alice/I05Bob.
Observer проверяет серверное состояние независимо от Minebridge API.

- Чат, ломание блока и вход в лаву вызывают обработчики, синхронные RPC,
  запись конкретных слотов игрока/сундука и телепортацию. Проверен native
  amplifier=199 для пользовательского level=200 и длительность до 2000 тиков.
- История по типам, aliases, withContext и двум процессам независима от live;
  getRecent/clear не забирают события у обработчиков или другой сессии.
- Заблокированный обработчик останавливается только после освобождения его
  функции; другая программа и RPC продолжают работу. Исключение обработчика
  видно вызывающему коду, соединение остаётся пригодным для команд.
- 600 настоящих native damage-событий переполняют Python live-очередь;
  ещё 600 при остановленном серверном writer переполняют серверную live-очередь.
  Источник ошибки различается, повторный poll снова сообщает о потере,
  другая сессия работает, ожидающий ACK мутации сохраняется.
- 4300 native damage-событий при лимите истории 4096 дают повторяемый
  EventHistoryLostError. getRecent сообщает ограниченность окна; другие типы
  не получают ложную потерю, clearPending позволяет явно перейти к хвосту.
- Старый установленный клиент 0.2.1 работает с новым плагином: прежние импорты,
  ID/блоки, игроки, предметы, keyword-эффекты, сущности и чат. Неизменённый
  examples/buffered_blocks.py выполнен обоими установленными клиентами.
- Короткий скрипт с двумя аргументами create, без flush/close, дожидается
  удержанной тестовым барьером команды и доставляет чат перед обычным выходом.
  logging=True пишет действия только своей сессии; результат мира одинаков.
- Закрытие убирает SDK-потоки. Остановка Paper будит ожидающего события читателя
  с ConnectionError. Повторный запуск с новым именем/UUID мира и теми же
  байтами config/портом работает без token/world, при выключенном TestControl.

Скорость
--------

Время включает отдельные buffered setBlock и завершающий flush, а не только
отправку. Logging выключен, event flood завершён; два игровых подключения,
TestControl включён одинаково на обоих плагинах. Четыре чанка измеряемой области
заранее загружены и удерживаются observer. У свежих процессов одинаковый
неизмеряемый прогрев 1000 блоков; SDK на новом сервере идут в порядке
0.3/0.2.1/0.2.1/0.3, по 6 измерений на размер для каждого SDK.

| Сценарий | Медиана 100 блоков, с | Медиана 1000 блоков, с |
|---|---:|---:|
| Плагин 0.3 + свежий SDK 0.3 | 0.053 | 0.424 |
| Плагин 0.3 + свежий SDK 0.2.1 | 0.051 | 0.425 |
| Плагин 0.2.1 + SDK 0.2.1, отдельный сервер, 3 измерения | 0.148 | 0.853 |
| Плагин 0.3 + долгая сессия после событий, 3 измерения | 0.249 | 0.851 |

На одном прогретом новом сервере свежие SDK показали близкие значения.
Старая пара и долгая сессия приведены отдельно: это разные запуски/предыстория,
из них нельзя выводить гарантированное ускорение или причину отличия.
Это локальные измерения одного стенда, без обещания такой же задержки по LAN,
при генерации новых чанков, другом железе или нагрузке целого класса.
Сырые повторы и условия: `.work/v03-i05-paper-results.json`.
