Приёмка T03
===========

Дата: 20 октября 2026 года. Статус: выполнено.

Python и Java одинаково разбирают кадры и сообщения протокола 1.0 по одному
корпусу из 247 сценариев. Кодеки не открывают сокеты, не авторизуют соединения
и не обращаются к миру. T04 и последующие этапы не реализовывались.

Что добавлено
-------------

- Python: _protocol.py, потоковый FrameDecoder, строгий JSON, формы запросов
  и ответов, безопасные DTO/диагностика, сериализация и таблица исключений.
- Java: JsonRpcCodec, FrameDecoder, JsonNumber, Request/Response/RpcError,
  CodecException и аналогичные проверки без Paper API.
- [Общий корпус](../../protocol/v1/fixtures/corpus.json) и его
  [формат](../../protocol/v1/README.md). Payload хранится в исходном виде,
  включая 1.0/1e0, дубликаты и намеренно повреждённые байты.
- Jackson core 2.22.4 включён в production JAR с переносом пакетов в
  dev.minebridge.internal.jackson.core через Shadow 9.3.0. Обе зависимости
  и транзитивные зависимости сборки зафиксированы lock/verification-файлами.
  Python по-прежнему не имеет runtime-зависимостей.

Узкие уточнения зафиксированы в разделе 3
[контракта r1](../contracts/V0_1_CONTRACT.ru.md): порядок предварительных проверок,
форма notification, дополнительные поля оболочки, целочисленные лексемы,
проверка hello-result и противоречий error.code/data.code. Wire-версия, API
и последовательность следующих этапов сохранены.

Проверки
--------

| Среда / проверка | Фактический результат |
|---|---|
| CPython 3.11.17, установленный wheel, python -I | 58 тестов, включая runner с 247 subtests; OK |
| CPython 3.14.7, установленный wheel, python -I | Те же 58 тестов и 247 subtests; OK |
| Gradle / JDK25 | 268 JUnit cases: 247 corpus + 13 codec + 8 config; 0 ошибок/пропусков |
| sdist → wheel в build isolation | Успешно; _protocol.py, JSON legacy-таблицы и py.typed включены |
| Изолированный ShadedCodecProbe | Успех с classpath только из test classes и production JAR, без Paper и внешнего Jackson |
| Проверка состава JAR | Jackson перенесён; исходных com/fasterxml/jackson и классов Paper API нет |
| Повторная принудительная сборка shadowJar | SHA-256 совпал; обычная offline-сборка с lock-файлами успешна |
| Настоящий Paper 26.2 build 133, обновлённый JAR | Все 4 сценария жизненного цикла T02 повторно прошли, exit 0 |

247 общих сценариев: 126 request, 46 hello-response, 54 blocks-response,
21 stream. Проверены UTF-8 при разрыве между байтами символа, CRLF, склейка
кадров, EOF, границы 65536/65537 байт и глубины 16/17, дубликаты после escape,
NaN/Infinity, границы ID/int32, числовые лексемы, обязательные поля и все
16 известных кодов ошибок. Дополнительные поля результата принимаются.

Отдельные regression-тесты проверяют приоритет глубины перед синтаксисом,
повторные ключи из нестандартных Mapping/Map и переопределённый int.__str__.
Сериализация не выпускает такой повреждённый JSON. Repr/toString, сообщения
и traceback codec не содержат тестовый токен и удалённый текст ошибки.

Проверка на Paper подтверждает загрузку упакованного плагина и жизненный цикл;
она не является проверкой handshake/установки блока. Весь codec проверен
офлайн. Две одновременные TCP-сессии появятся в тестах следующих этапов.
После серверного прогона тестовая JVM остановлена.
