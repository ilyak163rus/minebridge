Приёмка T01
===========

Дата: 20 октября 2026 года. Статус: выполнено.

Реализованы только офлайн-модели и валидация. Minecraft.create, TCP и Minecraft-
операции отсутствуют. T00: контракт r1 протокола 1.0 принят как рабочая база.

- AIR/STONE/COBBLESTONE — статические Final[LegacyBlock] с .id/.data.
- BlockSpec и LegacyBlock неизменяемы; states копируется в read-only mapping.
- Все поддержанные входы нормализуются в одинаковую спецификацию.
- Только три legacy-пары; неизвестные пары не заменяются воздухом.
- Проверяются bool, типы, состояния, конечность, floor и int32. Огромный legacy
  ID не вызывает ошибку форматирования сообщения; добавлен регрессионный случай.
- Runtime-зависимостей нет; py.typed и JSON поставляются вместе с пакетом.

Проверки выполнены из установленного wheel, без editable-install и без
PYTHONPATH на src, через python -I -m unittest discover:
