=====================================

Реализовано
-----------

- `effects.add(targets,effect,duration,level=1,*,particles=True)`:
  секунды, затем уровень. Старые keyword-вызовы и wire-форма сохранены.
- `mc.setPos` и `mc.players.setPos` — алиасы существующего teleport,
  с первым аргументом selector/target, дробями, world и TargetResult.
- `players.get/setGameMode`, `get/setHealth`, `get/setFoodLevel`.
  Setters предвалидируют всю группу, используют bounded jobs и проверяют
  фактическое состояние. Отменённое изменение не объявляется успехом.
- `effects.remove` и `effects.clear` для живых целей. Отсутствующий эффект —
  идемпотентный успех; отмена снятия другим плагином — per-target отказ.
- `worlds.get/setTime`, `get/setWeather`, `get/setGameRule`, без обязательного
  имени мира. Мир сессии закреплён за UUID; можно явно выбрать другой загруженный.
- Статические типизированные `gamemode`, `weather`, `gamerule`.
- `server.getInfo`/`getCapabilities`: неизменяемые локальные данные hello,
  без скрытого RPC и обещаний текущих TPS.
- `with Minecraft.create(...) as mc`: ожидание записей и закрытие;
  ошибка закрытия не скрывает уже возникшее исключение тела блока.

```python
from minebridge import Minecraft, effects, gamemode, selector

with Minecraft.create("192.168.0.200", 4712, player="CurrentNick") as mc:
    print(mc.server.getInfo())
    mc.setPos(selector.SELF, 10.5, 80, 10.5)
    print(mc.players.setGameMode(selector.SELF, gamemode.CREATIVE))
    print(mc.effects.add(selector.SELF, effects.SPEED, 100, 200))
    print(mc.effects.remove(selector.SELF, effects.SPEED))
```

Bulk-результат нужно проверять: applied/targets отражают отмену, исчезновение
цели и частичное исполнение; rollback не обещается. HP — очки здоровья,
не сердечки. Float32-точность учитывается до проверки максимума/readback:
`1.1` фактически читается как `1.100000023841858`. Положительное underflow
в ноль отклоняется до мутаций, скрытого clamp нет.

Gamerules
---------

Из живого Registry.GAME_RULE закреплённого сервера экспортированы **59 правил**:
47 bool и 12 int. Добавлены 23 identity-safe legacy alias — всего 82 константы.
DO_DAYLIGHT_CYCLE ссылается на ADVANCE_TIME (`minecraft:advance_time`),
KEEP_INVENTORY — на `minecraft:keep_inventory`.

Пять старых wrappers преобразуют/инвертируют значения и не выданы за aliases:
ALLOW_FIRE_TICKS_AWAY_FROM_PLAYER, DISABLE_ELYTRA_MOVEMENT_CHECK,
DISABLE_PLAYER_MOVEMENT_CHECK, DISABLE_RAIDS, DO_FIRE_TICK. Старый bool
DO_FIRE_TICK нельзя незаметно подменить современным целочисленным радиусом огня.
Используются canonical registry keys.

[Снимок](../../catalogs/paper-26.2-build133-gamerules.json), SHA-256:
`84daf9b4dafa7a9e8092fcfe27ffb26a2ed45fbb63b63a7a85f4b39e73e0c476`.
Provenance Paper/API/exporter проверен, генератор `--check` прошёл.
[Экспорт и ограничения](../../catalogs/README.md).

Диапазоны int-правил не выводятся из default. Сверка bytecode закреплённого
CraftWorld подтверждает canonical codec validation до native изменения.
Runtime проверены bool/int, неизвестный ключ и int32-границы; отдельный
тест RANDOM_TICK_SPEED=-1 в данный прогон не включался.

Проверки
--------

- **546 Java-тестов**, без failures/errors/skips: 57 новых общих codec-сценариев,
  10 проверок player/gameplay controls и 9 проверок WorldsService.
  Общий корпус теперь содержит 343 сценария.
- **По 181 Python-тесту** на 3.11.17 и 3.14.7, успешно. По два installed-package
  теста пропущены намеренно: I01 проверяет исходники, wheel не строится.
  Добавлены 11 проверок API/моделей/каталога/capabilities/закрытия.
- Настоящий Paper: **11/11 сценариев**, два genuine игровых TCP-клиента и два
  отдельных Python-процесса с разными session UUID. Независимый console observer
  читает состояние напрямую через Paper API.
- Режим SELF/ALL и отказ при отмене GameMode другим listener. Остальные цели
  и вторая программа продолжают работать.
- Разный максимум HP двух игроков: недопустимое для второго групповое значение
  отклонено до изменения первого. Проверены float32 readback, underflow и
  сытость; в стенде явно отключена естественная регенерация.
- Позиционные/keyword эффекты наблюдались как durationTicks=1998,
  amplifier=199/level=200. Remove/clear идемпотентны; заблокированное снятие
  вернуло EFFECT_REJECTED, эффект действительно остался.
- Оба setPos и старый teleport сохранили дробные позиции; отдельно телепорт
  в дальнюю область `(24000.25,220.5,24000.75)` с загрузкой чанка.
- Canonical/alias/raw-string gamerules и серверное отклонение неверного типа.
  Время `23000 → 1000` дало fullTime `23000 → 25000`, как предусматривает Paper.
- Все погодные состояния и оба flags сверены независимо. Отмена погоды другим
  listener дала WorldChangeRejectedError/outcome=unknown без ложного applied.
- Context manager дождался блока/чата и сохранил исходное исключение.
  Локальные сведения не увеличивали request counter. Logging включался только
  у запросившей его сессии; второй клиент оставался без журнала действий.
- Остановка с exitCode=0, без ERROR; клиенты без ошибок, порты свободны,
  receiver threads после close отсутствуют. Хеши 37 source-файлов и входных
  JAR/scripts совпали после прогона.
