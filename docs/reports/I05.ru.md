Что можно использовать
----------------------

`Minecraft.create(ip, port)` без обязательных token/world, buffered по умолчанию,
явный `writeMode="sync"`, `flush` и ожидающий завершения `close`.
Установка/чтение блока и включённой области, числовые ID и современный BlockSpec
со свойствами, автоматическая загрузка/генерация чанков. Игроки: ID, список,
позиция, телепортация; отдельный контекст SELF по текущему онлайн-нику,
vanilla-селекторы. Выдача предметов с учётом остатков, эффекты, создание
сущностей и чат. Статические типизированные каталоги доступны без сервера.

Каталоги: 1196 блоков, 1537 предметов, 40 эффектов, 158 типов сущностей.
Legacy-таблица содержит 361 пару ID/data для 110 старых ID. Современные блоки
без однозначного старого соответствия читаются через `mc.blocks.*`;
корневой числовой API сообщает UnsupportedLegacyBlockError. Из типов сущностей
150 обычных, 7 со специальными адаптерами; PLAYER требует входа игрового клиента.
Точные параметры и ограничения приведены в справочнике и контракте.

Совместная проверка Paper
------------------------

Paper 26.2 build 133 / Temurin JDK 25.0.4.1+1, Windows x64, loopback.
Два отдельных Python-процесса (PID 18904/34456) используют установленный wheel
0.2.0 и разные session UUID. Два headless игровых TCP-клиента действительно
вошли на сервер; UUID/runtime ID, инвентари, эффекты и изменения мира сверены
независимым console observer. Это не искусственные Bukkit-игроки.

Все 17 объединённых сценариев прошли с первого полного запуска:

- Игроки, контекст исходного/производного фасада, очистка SELF, vanilla-селекторы,
  типизированные ошибки; независимый SELF двух процессов при выдаче наград.
- Обычная, частичная и полная выдача, имена/lore и `overflow="drop"`;
  эффекты игроку/живой сущности, предвалидация смешанного набора целей.
- Обычные сущности и все семь специальных адаптеров. Для настоящей молнии
  observer подтвердил damage-событие от её UUID, effect=false и здоровье 10→5.
  Жертва предварительно находилась в активно симулируемой области рядом с игроком.
- Дробная позиция/телепортация, получение чата настоящими игровыми соединениями.
- Числовые/современные блоки, состояния, отрицательные координаты, обе границы
  и обратный порядок углов, барьер чтения. Два процесса одновременно выполняют
  непересекающиеся заливки; интервалы вызовов действительно перекрываются.
  Конфликт занятой области сообщает RegionBusyError, другая сессия продвигается.
- Ранее незагруженные чанки для чтения/записи, spawn и teleport;
  явное несовпадение мира контекста и сохранение глобального смысла `@a`.
- Отложенная ошибка на следующей записи, `flush`, чтении и `close`.
  При одном намеренном разрыве ACK — unknown, одно соединение/одно изменение,
  без автоматического повтора. Остановка с ожидающей записью ограничена по времени.
- Второй свежий основной мир с новым именем/UUID, теми же байтами конфига,
  `TestControl=false`: ровно два аргумента `create`, без token/world, установка
  и чтение блока через публичный API. Оба сервера завершились с exitCode=0, без ошибок
  в журнале; собственные потоки/процессы закрыты, игровые и bridge-порты свободны.

Измерения скорости
-----------------

Время включает подтверждение завершения через `flush`, а не только отправку.
Обычные инертные блоки в заранее загруженной области, два игрока на сервере.

| Сценарий | Фактическое время |
|---|---|
| 100 отдельных `setBlock`, buffered, медиана 5 запусков | 0,19783 с |
| 1000 отдельных `setBlock`, buffered, 2 запуска | 1,29878 / 0,95000 с |
| 100 отдельных `setBlock`, sync | 4,99739 с |
| Новая область: загрузка/генерация, чтение и запись | 0,51183 с |
| Остановка с ожидающей записью | 0,93897 с |

Независимые показания Paper до/после серии: TPS 19,527/19,643,
average tick 8,145/1,504 мс. Это контрольные измерения локального стенда;
они не обещают такую задержку по LAN, при любой генерации или нагрузке класса.

Пользовательский LAN и Paper build 99 этим прогоном не проверялись.
Проверка одного локального сервера с двумя клиентами не является нагрузочным
испытанием полного класса. Автозагрузка гарантирует выполнение операции,
а не бессрочную симуляцию сущности после освобождения чанка; дальнейшее
поведение определяется обычными правилами Minecraft. Scoreboard, title/actionbar,
события Python, undo, произвольные NBT/компоненты и зачарования в 0.2 не входят.
Исторические поставки и отчёты предыдущих итераций сохранены.
