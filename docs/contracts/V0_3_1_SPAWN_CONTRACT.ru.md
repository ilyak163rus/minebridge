Создание сущностей в мирном режиме — дополнение 0.3.1
===================================================

29 октября 2026 года. Протокол 2.0 остаётся совместимым: добавлен код
`PEACEFUL_SPAWN_BLOCKED` (`-32053`), Python-класс `errors.PeacefulSpawnError`.
Сообщение: `Cannot spawn this entity because the destination world is in Peaceful difficulty`.

Проверяется **мир назначения**, после ожидания загрузки чанка и непосредственно
перед вызовом Paper spawn. Изменение сложности во время загрузки учитывается.
Ошибка имеет `outcome="not-applied"`: метод создания сущности ещё не вызывался.
Сложность не меняется автоматически; повторов запроса нет. Соединение остаётся
работоспособным, в том числе для создания разрешённых мирных существ.

Критерий запрета — 38 флагов `EntityTypes.Builder.notInPeaceful` закреплённого
Paper 26.2 build 133, проверенных по байткоду серверного JAR, а не интерфейс
Monster/Enemy. Giant запрещён; Ghast, Slime и Hoglin также запрещены. Shulker,
Piglin и Ender Dragon разрешены этим критерием, несмотря на Enemy. Прочие
проверки спавна по-прежнему действуют. Bukkit API не предоставляет данный флаг;
таблица хранится в чистом Java `PeacefulSpawnPolicy`, без runtime NMS/reflection.
Для новой поддерживаемой версии Minecraft таблицу нужно сверить заново.

Некорректный/неподдерживаемый тип, отмена спавна другим плагином и прочие сбои
не объявляются ошибкой мирной сложности только по совпадению режима мира.
Существующие ошибки и `outcome="unknown"` после входа в мутацию сохраняются.

Проверки: общие Java/Python corpus frames, точечная политика с разрешёнными
исключениями, запрет после ожидания чанка без мутации/утечки ticket, TCP-тест
Python с типизированной ошибкой и последующим успешным запросом. Приёмка
на настоящем сервере фиксируется отдельным отчётом поставки.
