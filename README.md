Первый технический результат: подключение → hello → один блок → подтверждение
после исполнения. Это ограниченный прототип; полная совместимость уроков mcpi,
селекторы, SELF, предметы, события и scoreboard входят в последующие срезы.
Публичный API работает через установленный Python-пакет и плагин. Токен урока
берётся из MINEBRIDGE_TOKEN. Выберите координаты загруженного чанка своего стенда:

```python
from minebridge.minecraft import Minecraft
from minebridge import block

mc = Minecraft.create("localhost", 4711)
try:
    mc.setBlock(0, 80, 0, 4)
    mc.blocks.setBlock(1, 80, 0, block.COBBLESTONE)
finally:
    mc.close()
```

Оба setBlock возвращают None после подтверждения сервера. [Пример](examples/set_block.py)
сохранён в репозитории. Поддержаны три legacy-пары 0/1/4 с data=0 и современные
ключи без состояний. Observer/gate и матрица V/D проверены в T08/T09;
обязательная N/F приёмка ошибок и сбоев остаётся T10.
