Таблица совместимости T01
========================

Единственный источник —
[legacy-blocks-v0.1.json](../python/src/minebridge/_data/legacy-blocks-v0.1.json).
Он расположен внутри Python-пакета и включается в wheel и sdist как package data.
Приложение читает его через importlib.resources, не из текущего каталога проекта.

Это техническое уточнение первоначального layout: файл за пределами python/
не переносится автоматически в самостоятельный sdist. Внутреннее размещение
позволяет обойтись без дубликатов и специальных сборочных hooks. API, значения
таблицы и объём T01 не меняются.
